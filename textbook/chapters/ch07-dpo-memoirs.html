New Orleans 2023: The Alignment Epiphany (DPO)

Reflections on attending NeurIPS 2023 in New Orleans, the collapse of complex 4-model PPO loops, closed-form preference optimization, and PyTorch implementation.

"For years after OpenAI released InstructGPT, those of us working on alignment were trapped in engineering purgatory. Training an aligned model required managing a fragile 4-model choreography: an Actor model, a Critic model, a Reference model, and a Reward model, all synchronized through Proximal Policy Optimization (PPO). GPU memory blew up, hyperparameter tuning was a nightmare, and policies frequently collapsed into reward-hacking reward exploitation. Then, in December 2023 at NeurIPS in New Orleans, Rafaelov et al. presented Direct Preference Optimization (DPO). Sitting in that hall, I watched them execute a piece of pure mathematical magic: by expressing the reward function implicitly through the policy itself, the intractable partition function canceled out completely! PPO's multi-model complexity was collapsed into a single, elegant binary cross-entropy loss."

— From the Memoirs of a Veteran AI Scholar

7.1 Deriving DPO from First Principles

Standard RLHF solves a KL-constrained reward maximization problem over prompt distribution \(\mathcal{D}\):

\[ \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta(y|x)} \left[ r(x,y) \right] - \beta \mathbb{D}_{\text{KL}}\left( \pi_\theta(y|x) \parallel \pi_{\text{ref}}(y|x) \right) \]

Expanding the KL divergence definition:

\[ = \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}} \left[ \beta \sum_{y} \pi_\theta(y|x) \log \left( \frac{\pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r(x,y)\right)}{\pi_\theta(y|x)} \right) \right] \]

Defining the normalizing partition function \(Z(x) = \sum_{y} \pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r(x,y)\right)\), the objective is maximized when the policy matches the target distribution \(\pi^*\):

\[ \pi^*(y|x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r(x,y)\right) \]

Solving directly for the implicit reward function \(r(x,y)\):

\[ r(x,y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} + \beta \log Z(x) \]

Now substitute this implicit reward into the Bradley-Terry preference model for winning completion \(y_w\) over losing completion \(y_l\):

\[ P(y_w \succ y_l \mid x) = \sigma \left( r(x, y_w) - r(x, y_l) \right) \]

Because \(Z(x)\) does not depend on completion \(y\), the partition terms \(\beta \log Z(x)\) cancel out completely! This yields the Direct Preference Optimization (DPO) objective:

\[ \mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right] \]

7.2 Ground-Zero PyTorch Implementation: DPO & Reference-Free SimPO

import torch
import torch.nn as nn
import torch.nn.functional as F

def dpo_loss(
    policy_chosen_logps: torch.Tensor,
    policy_rejected_logps: torch.Tensor,
    ref_chosen_logps: torch.Tensor,
    ref_rejected_logps: torch.Tensor,
    beta: float = 0.1
) -> torch.Tensor:
    """
    Computes exact Direct Preference Optimization (DPO) Loss.
    Log probabilities shape: (batch_size,)
    """
    pi_logratios = policy_chosen_logps - policy_rejected_logps
    ref_logratios = ref_chosen_logps - ref_rejected_logps
    
    logits = pi_logratios - ref_logratios
    loss = -F.logsigmoid(beta * logits)
    return loss.mean()

def simpo_loss(
    policy_chosen_logps: torch.Tensor,
    policy_rejected_logps: torch.Tensor,
    chosen_lens: torch.Tensor,
    rejected_lens: torch.Tensor,
    beta: float = 2.0,
    gamma: float = 0.5
) -> torch.Tensor:
    """
    Computes Simple Preference Optimization (SimPO) Loss.
    Eliminates reference model by using length-normalized log-probs and target margin gamma.
    """
    # Length-normalized log probabilities
    chosen_norm_logps = policy_chosen_logps / chosen_lens
    rejected_norm_logps = policy_rejected_logps / rejected_lens
    
    logits = chosen_norm_logps - rejected_norm_logps - gamma
    loss = -F.logsigmoid(beta * logits)
    return loss.mean()

# --- Verification ---
if __name__ == "__main__":
    p_chosen = torch.tensor([-2.1, -1.5])
    p_rejected = torch.tensor([-4.5, -3.8])
    r_chosen = torch.tensor([-2.0, -1.4])
    r_rejected = torch.tensor([-3.0, -2.5])
    
    loss_val = dpo_loss(p_chosen, p_rejected, r_chosen, r_rejected, beta=0.1)
    print(f"Calculated DPO Loss: {loss_val.item():.6f}")
