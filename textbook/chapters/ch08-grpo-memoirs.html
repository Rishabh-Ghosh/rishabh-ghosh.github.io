ICLR 2025: DeepSeek-R1, GRPO & System 2 Reasoning

Reflections on the frontier of AI research: Group Relative Policy Optimization (GRPO), Process-Supervised Reward Models (PRMs), emergent self-correction, and PyTorch implementation.

"In recent years at ICLR and ICML, a profound paradigm shift has taken place: the transition from intuitive 'System 1' text generation to deliberate 'System 2' reasoning. For a long time, researchers believed that teaching LLMs to solve Olympiad math or write complex code required massive human-annotated reasoning datasets. But when DeepSeek unveiled their work on DeepSeek-R1 and Group Relative Policy Optimization (GRPO), I was stunned by the elegance of their approach. By discarding the massive Critic network entirely and sampling groups of candidate completions scored against objective rule-based verifiers, pure Reinforcement Learning induced emergent self-correction, reflection, and long thinking traces without a single piece of human instruction data!"

— From the Memoirs of a Veteran AI Scholar

8.1 The Mathematics of Group Relative Policy Optimization (GRPO)

In standard PPO, a Critic network matching the scale of the Actor (e.g., 70B+ parameters) estimates baseline values \(V(s)\). GRPO (Shao et al., 2024/2025) eliminates the Critic network completely.

For each prompt query \(q\), GRPO samples a group of \(G\) candidate completion outputs \(\{o_1, o_2, \dots, o_G\}\) from the old policy \(\pi_{\text{old}}\). Rewards \(\{r_1, r_2, \dots, r_G\}\) are assigned via rule-based execution or reward models. The advantage \(A_i\) for completion \(o_i\) is computed by normalizing relative to the group:

\[ A_i = \frac{r_i - \text{mean}(\{r_1, \dots, r_G\})}{\text{std}(\{r_1, \dots, r_G\}) + \epsilon} \]

The complete GRPO clipped surrogate objective maximizes relative advantages while penalizing KL divergence against a reference model \(\pi_{\text{ref}}\):

\[ \mathcal{L}_{\text{GRPO}}(\theta) = \frac{1}{G} \sum_{i=1}^G \min \left( \frac{\pi_\theta(o_i|q)}{\pi_{\text{old}}(o_i|q)} A_i, \text{clip}\left(\frac{\pi_\theta(o_i|q)}{\pi_{\text{old}}(o_i|q)}, 1-\epsilon, 1+\epsilon\right) A_i \right) - \beta \mathbb{D}_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}}) \]

8.2 Ground-Zero PyTorch Implementation: GRPO Advantages & Surrogate Loss

import torch
import torch.nn as nn
import torch.nn.functional as F

def compute_grpo_advantages(rewards: torch.Tensor, eps: float = 1e-8) -> torch.Tensor:
    """
    Computes group-relative normalized advantages.
    rewards shape: (B, G) where B is batch size of prompts and G is group size.
    """
    mean_r = rewards.mean(dim=-1, keepdim=True)
    std_r = rewards.std(dim=-1, keepdim=True)
    advantages = (rewards - mean_r) / (std_r + eps)
    return advantages  # Shape: (B, G)

def grpo_surrogate_loss(
    policy_seq_logps: torch.Tensor,  # (B, G) sum of log probabilities per sequence
    old_seq_logps: torch.Tensor,     # (B, G)
    advantages: torch.Tensor,        # (B, G)
    clip_eps: float = 0.2
) -> torch.Tensor:
    """
    Computes GRPO clipped surrogate policy loss.
    """
    ratios = torch.exp(policy_seq_logps - old_seq_logps)
    
    surr1 = ratios * advantages
    surr2 = torch.clamp(ratios, 1.0 - clip_eps, 1.0 + clip_eps) * advantages
    
    loss = -torch.min(surr1, surr2).mean()
    return loss

# --- Verification ---
if __name__ == "__main__":
    # 2 prompts, group size 4 completions each
    sample_rewards = torch.tensor([[1.0, 0.0, 0.0, 0.0],  # Prompt 1: 1 correct answer out of 4
                                   [1.0, 1.0, 0.0, 0.0]]) # Prompt 2: 2 correct answers out of 4
    
    advs = compute_grpo_advantages(sample_rewards)
    print("Calculated GRPO Advantages:\n", advs)
