Chapter 06

Direct & Implicit Preference Optimization (DPO)

Mathematical derivation of Direct Preference Optimization (Rafailov et al., 2023), implicit reward transformations, loss gradient mechanics, and reference-free extensions (IPO, KTO, SimPO).

6.1 The RLHF Constrained Optimization Problem

In traditional RLHF (Christiano et al., 2017; Ziegler et al., 2019), policy optimization seeks a language model policy \( \pi_\theta \) that maximizes an explicit reward function \( r^\phi(x,y) \) subject to a KL-divergence penalty against a reference policy \( \pi_{\text{ref}} \):

\[ \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta(y|x)} \left[ r^\phi(x,y) \right] - \beta \mathbb{D}_{\text{KL}}\left( \pi_\theta(y|x) \parallel \pi_{\text{ref}}(y|x) \right) \]

Expanding the KL divergence definition:

\[ \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}} \left[ \sum_{y} \pi_\theta(y|x) \left( r^\phi(x,y) - \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} \right) \right] \]

Rearranging terms inside the expectation:

\[ = \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}} \left[ \beta \sum_{y} \pi_\theta(y|x) \log \left( \frac{\pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r^\phi(x,y)\right)}{\pi_\theta(y|x)} \right) \right] \]

6.2 Deriving the Optimal Policy in Closed Form

Define the unnormalized target distribution \( Z(x) \):

\[ Z(x) = \sum_{y} \pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r^\phi(x,y)\right) \]

Defining the valid probability distribution \( \pi^*(y|x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r^\phi(x,y)\right) \), the optimization objective becomes:

\[ \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}} \left[ \beta \log Z(x) - \beta \mathbb{D}_{\text{KL}}\left( \pi_\theta(y|x) \parallel \pi^*(y|x) \right) \right] \]

Because KL divergence is non-negative and equals zero if and only if the distributions match, the exact global optimum policy \( \pi^* \) satisfies:

\[ \pi_\theta(y|x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y|x) \exp\left(\frac{1}{\beta} r^\phi(x,y)\right) \]

6.3 Substituting Implicit Rewards into Bradley-Terry Preference Loss

Taking the logarithm of both sides of the optimal policy equation and solving directly for the reward function \( r^\phi(x,y) \):

\[ r^\phi(x,y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} + \beta \log Z(x) \]

Now recall the **Bradley-Terry preference model** (Bradley & Terry, 1952), which models human preference likelihood for winning response \( y_w \) over losing response \( y_l \) given prompt \( x \):

\[ P(y_w \succ y_l \mid x) = \sigma \left( r^\phi(x, y_w) - r^\phi(x, y_l) \right) \]

Substituting our implicit reward formula into the Bradley-Terry preference probability, the partition function term \( \beta \log Z(x) \) cancels out completely!

\[ r^\phi(x, y_w) - r^\phi(x, y_l) = \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \]

This yields the complete **Direct Preference Optimization (DPO)** objective function:

\[ \mathcal{L}_{\text{DPO}}(\theta; \pi_{\text{ref}}) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right] \]

6.4 Gradient Dynamics & Intuitively Understanding DPO

Taking the derivative of \( \mathcal{L}_{\text{DPO}}(\theta) \) with respect to policy parameters \( \theta \):

\[ \nabla_\theta \mathcal{L}_{\text{DPO}}(\theta) = -\beta \mathbb{E}_{(x, y_w, y_l)} \left[ \underbrace{\sigma \left( \hat{r}_\theta(x, y_l) - \hat{r}_\theta(x, y_w) \right)}_{\text{Weighting factor / Error margin}} \left( \nabla_\theta \log \pi_\theta(y_w|x) - \nabla_\theta \log \pi_\theta(y_l|x) \right) \right] \]

Key gradient properties:

  • Increases the log-likelihood of winning response $y_w$ while decreasing log-likelihood of losing response $y_l$.
  • The gradient step is weighted by $\sigma(\hat{r}_\theta(y_l) - \hat{r}_\theta(y_w))$, which scales up when the model incorrectly ranks $y_l > y_w$ and scales down when the model is already confident.
  • Eliminates the need to train or store an explicit Reward Model network or execute PPO sampling loops!

PyTorch Production Implementation: DPO Loss

import torch
import torch.nn as nn
import torch.nn.functional as F

def compute_dpo_loss(
    policy_chosen_logps: torch.Tensor,
    policy_rejected_logps: torch.Tensor,
    ref_chosen_logps: torch.Tensor,
    ref_rejected_logps: torch.Tensor,
    beta: float = 0.1,
    label_smoothing: float = 0.0
) -> tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    Computes DPO loss for a batch of chosen (winning) and rejected (losing) completions.
    """
    # Log-ratios of policy probabilities vs reference probabilities
    pi_logratios = policy_chosen_logps - policy_rejected_logps
    ref_logratios = ref_chosen_logps - ref_rejected_logps

    logits = pi_logratios - ref_logratios
    
    if label_smoothing > 0.0:
        # Robust DPO variant with label smoothing
        losses = -F.logsigmoid(beta * logits) * (1 - label_smoothing) - F.logsigmoid(-beta * logits) * label_smoothing
    else:
        losses = -F.logsigmoid(beta * logits)

    # Compute implicit rewards for logging and monitoring
    chosen_rewards = beta * (policy_chosen_logps - ref_chosen_logps).detach()
    rejected_rewards = beta * (policy_rejected_logps - ref_rejected_logps).detach()

    return losses.mean(), chosen_rewards.mean(), rejected_rewards.mean()

6.5 Advanced Variants: IPO, KTO, ORPO & SimPO

Algorithm Objective Focus Key Innovation
IPO (Azar et al., 2023) Square Error Regularization Prevents greedy over-fitting in DPO by penalizing squared log ratios.
KTO (Ethayarajh et al., 2024) Unpaired Utility Function Applies Prospect Theory (Kahneman-Tversky) to binary good/bad feedback without pairs.
ORPO (Hong et al., 2024) Odds-Ratio Penalty Combines SFT negative log-likelihood loss with Odds Ratio penalty in one stage without reference model.
SimPO (Meng et al., 2024) Length-Normalized Margin Eliminates reference model entirely; uses target margin $\gamma$ with sequence-length normalized probabilities.
